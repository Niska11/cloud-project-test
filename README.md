# Codex Cloud 回流验证项目

这个项目用于验证一个行为：

在 Codex 云端 Web 里，针对同一个 GitHub 仓库新开的 Codex Cloud 对话，最终会不会回流到桌面端原来的本地项目里，还是会出现在一个新的云端项目或仓库分组里。

## 验证背景

- 这是刚新建的测试项目。
- 当前本地项目路径：`/Users/xukehan/Documents/codex-local-cloud-test`
- 目标是观察同一个 GitHub 仓库在桌面端和云端 Web 之间的项目归属、对话归属和同步表现。

## 观察点

- 云端 Web 新开的对话是否能关联到桌面端原来的本地项目。
- 云端 Web 是否会创建新的项目或仓库分组。
- 后续提交、分支或对话记录是否能在两个入口之间正确对应。
